# Texas Hold'em Preflop Rules

## Action Order
- After blinds are posted (SB and BB), action begins **to the left of the big blind** (LJ in 6-max)
- Action continues **clockwise** around the table

## The Three Main Preflop Actions

### 1. Fold (弃牌)
- Discard your hand and forfeit any chips already committed to the pot
- **Available at any time** when it's your turn (except when checking is the only option)
- You give up your chance to win the current hand

### 2. Call/Check (跟注/过牌)
- **Call**: Match the current bet amount
  - Preflop, this typically means matching the **big blind amount** (or matching a previous raise)
  - "Limping" = calling the big blind without raising
- **Check**: Only available if no betting action has occurred before your turn
  - In BB, if no one has raised, you can "check" (effectively a call with $0 additional)

### 3. Raise (加注)
- **Increase** the bet beyond the current amount
- Any raise must increase the current bet by at least the minimum required amount
- Can be:
  - **Open**: First raise of the hand (when no one has raised yet)
  - **3-Bet**: Second raise (re-raising an open)
  - **4-Bet**: Third raise
  - **5-Bet**: Fourth raise

## Action Availability Rules

### When NO ONE has raised yet (only blinds posted):
- **Fold**: Available to all (except technically BB shouldn't fold since they can check for free)
- **Call/Limp**: Available to all - call the big blind amount
- **Raise/Open**: Available to all - make the first raise

Example:
- LJ folds → HJ can: Fold, Call (limp to BB), or Open (raise)

### When facing a raise:
- **Fold**: Always available
- **Call**: Match the raise amount
- **Raise**: Re-raise (3-bet, 4-bet, or 5-bet depending on raise count)

### Special Case: Big Blind
- If everyone folds/limps to BB, BB can:
  - **Check** (no additional bet, see flop for free)
  - **Raise** (open the betting)
- If someone has raised, BB must choose: Fold, Call, or Raise
