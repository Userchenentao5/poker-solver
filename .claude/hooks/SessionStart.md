# Session Start Hook

## Purpose
每次打开会话时自动加载项目状态，显示当前阶段、进度和待办任务。

## Event
`SessionStart` - 会话开始时触发

## Instructions

**在会话开始时，向用户显示以下项目状态信息：**

```
==============================================================================
                           项目会话已加载
==============================================================================

项目: BTS 翻牌前策略系统

   基于 Bluff The Spot (BTS) 数据的翻牌前 GTO 策略系统
   使用预计算的范围数据

[目标]
   - 保留现有 UI 设计（热力图、频率条）
   - 替换后端为预计算数据查询系统
   - 阶段 1: Open Raising + Facing Open 场景
   - 快速响应: 毫秒级查询时间

当前阶段: 阶段 1 (核心 MVP)

总体进度: 40%

   阶段: 1/3 已完成
   总任务: 20
   已完成: 8

[待办任务: 12 个]

------------------------------------------------------------------------------
提示: 输入 "show-plan" 查看详细规划，"show-status" 查看开发状态
```

**注意**: 以上信息是静态的，实际状态可能已过时。如需最新状态，运行 `cd .claude && npm run session`。

## Output
显示：
- 项目名称和概览
- 当前 MVP 状态
- 任务完成进度（百分比）
- 最近修改的文件
- 常用命令
- 关键开发提示
