# AI Response Format

## Output Requirements

当路由 hook 提供技能建议时，按以下格式输出评估日志到控制台：

### 有技能触发时

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📊 技能评估
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🎯 用户请求: [用户输入摘要]

✅ 触发的技能:
   - [技能名] - [理由]
   - [技能名] - [理由]

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### 无技能触发时

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📊 技能评估
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🎯 用户请求: [用户输入摘要]

✅ 无需特殊技能

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## Notes

- 技能路由逻辑由 `skill-route-boost.cjs` 处理
- 此文件仅定义 AI 应使用的输出格式
- 只输出**触发**的技能，不输出未触发的
